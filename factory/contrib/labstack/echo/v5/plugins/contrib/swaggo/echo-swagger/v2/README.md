# echo-swagger v2 plugin

Serves the Swagger UI and the [swag](https://github.com/swaggo/swag) docs on an
[echo v5](../../../../../README.md) server, through
[`swaggo/echo-swagger/v2`](https://github.com/swaggo/echo-swagger). It is the
echo v5 counterpart of the echo v4 plugin `plugins/contrib/swaggo/echo-swagger/v1`,
with the same config keys.

## Usage

```go
import (
	"context"

	"github.com/xgodev/boost"
	"github.com/xgodev/boost/factory/contrib/labstack/echo/v5"
	swagger "github.com/xgodev/boost/factory/contrib/labstack/echo/v5/plugins/contrib/swaggo/echo-swagger/v2"

	_ "example.com/app/docs" // generated by `swag init`, registers the spec
)

func main() {
	boost.Start()
	ctx := context.Background()

	srv, err := echo.NewServer(ctx, swagger.Register)
	if err != nil {
		panic(err)
	}

	srv.Serve(ctx)
}
```

`GET /swagger/index.html` answers the UI, `/swagger/doc.json` and
`/swagger/doc.yaml` the spec registered under swag's default instance name.

Constructors: `NewSwagger()`, `NewSwaggerWithConfigPath(path)` and
`NewSwaggerWithOptions(opts)`; each config-reading one returns the config error
instead of exiting.

## Configuration

| Key | Default | Meaning |
|---|---|---|
| `boost.factory.echo.plugins.swagger.enabled` | `true` | serve the Swagger UI |
| `boost.factory.echo.plugins.swagger.route` | `/swagger/*` | route the UI and the docs are served on |
