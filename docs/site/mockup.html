github.com/xgodev/boost · bootstrap

One boot. Everything ready after it.

boost.Start() runs first. When it returns, config is loaded and the logger is set, so every factory reads its own keys and logs the same way.

  1. 01boost.Start()Reads flags, env vars and config files.
  2. 02configEvery key declared once, with a default and a description.
  3. 03logzap, zerolog or logrus behind one wrapper.
  4. 04factoryOne constructor per component, plugins applied.
  5. 05fxGenerated modules wire the dependency graph.
  6. 06serveREST, gRPC, MCP or an event function.

One key, three ways to set it

Keys live under boost.factory.<component>.* and reach the app from wherever you deploy.

keyboost.factory.zap.console.level
envBOOST_FACTORY_ZAP_CONSOLE_LEVEL=DEBUG
flag--boost.factory.zap.console.level=DEBUG
func main() {
	boost.Start()
	fx.New(gen.Module()).Run()
}

builder · inject · annotation

From annotation to binary in two commands.

You write handlers, services and annotations. Everything that repeats between services is generated, checked and rewritten on every run.

  1. Annotate

    Mark constructors with @Provide, handlers with a door, services with @Middleware, the default implementation with @Default.

  2. Generate

    Inject and builder run in one pass. A broken graph stops here and leaves your output untouched.

    go generate ./...

  3. Run

    Each app gets its own main, with the servers and plugins it declared.

    go run ./cmd/api

backward compatibility

Upgrade boost.
Keep your code.

A minor release never asks you to rewrite a service. That is a rule of the project, enforced on every pull request.

Public API is a contract

A component's public API does not break without a major version bump and a written reason. Any observable change ships with a test first.

SDK majors live side by side

Factory paths carry the upstream major. Moving to a new SDK is an import you choose, not a forced migration.

factory/contrib/go.mongodb.org/mongo-driver/v1   // keeps working
factory/contrib/go.mongodb.org/mongo-driver/v2   // new SDK major

A gate that only moves forward

Every PR is compared to develop: format, lint, build and tests can stay the same or get better, never worse.
