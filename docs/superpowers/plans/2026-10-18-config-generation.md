# @Config generation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** generate the `config.Add` registration and the `*Struct` provider of a `@Config` struct, so a package declares only the struct.

**Architecture:** the annotation collector records struct fields; inject turns a `@Config` struct into a provider component of `*Struct` (edges, dependent modules and the root module work unchanged) and renders it with a `config` template; builder collects `@Config` and reads provided types through `Component.Result`.

**Tech Stack:** Go 1.26, uber fx v1.24, koanf v1 via `wrapper/config`.

**Spec:** `docs/superpowers/specs/2026-10-18-config-generation-design.md`

Execution: native in this session (the maintainer forbids subagents).

## Global Constraints

- Generated header: `// Code generated by inject; DO NOT EDIT.`
- Key segments are env-reachable: root from `keySegments(rel path)`, field segment lowerCamel of the field's words.
- Supported field types: `string`, `bool`, `int`, `int8`, `int16`, `int32`, `int64`, `uint`, `uint8`, `uint16`, `uint32`, `uint64`, `float32`, `float64`, `time.Duration`, `[]string`.
- `desc` required; `default` optional (zero value); `hide:"true"`; `config:"name"` must match `^[a-z][a-zA-Z0-9]*$`; `config:"-"` skips the field.
- Every error is a boost `errors.NotValidf` / `AlreadyExistsf` naming the struct (`path.Struct`) and the field.
- No public API removed; `gocyclo` stays under 15 per function.

## Review Focus

- `time.Duration` written through an import alias (`import t "time"`) is still a duration: resolve the selector through `Entry.Imports`.
- A field named with an acronym (`BaseURL`, `HTTPTimeout`) gets the segment the env loader builds (`baseUrl`, `httpTimeout`), not `baseURL`.
- A `@Config` struct no constructor receives still generates its module and joins the root module.
- `[]string` set from env (`a,b`) reaches the struct split by comma.
- A struct with other inject annotations but no `@Config` keeps today's warn-and-ignore.

### Task 2: inject parses `@Config` into a component

**Files:** Modify `inject/spec.go` (ENUM gains `CONFIG`; run `go generate ./inject` with go-enum), `inject/component.go`, `inject/graph.go`, `inject/implementation.go`, `inject/graphviz.go`, `inject/collector.go`; Create `inject/config.go`; Test `inject/config_test.go`, `inject/graph_test.go`.

**Interfaces:**
- `type ConfigField struct { Name, Segment, Kind, Type, Default, Desc string; Hide bool }` (`Kind` one of the supported types, `Default` the Go literal).
- `Component.Config []ConfigField`; `Component.IsConfig() bool` (`Entry.IsStruct()`).
- `Component.Result(idx int) string`: `"*"+Entry.Struct` for a config, else `Entry.Func.Results[idx].Type`.
- `declName(entry) string`: `Func.Name`, or `Struct` for a struct; used by `gid`, graphviz, `ModuleOf`.
- `newConfig(entry annotation.Entry) (Component, error)`: `Provides: {0: {}}`, `Type: AnnotationTypePROVIDE`.

- [ ] Tests in `config_test.go` (table, via `newComponent`):
  - `BaseURL string default:"http://x" desc:"d"` -> segment `baseUrl`, literal `"http://x"`;
  - `Timeout time.Duration default:"1m30s"` -> `90 * time.Second`; `default:"2s"` -> `2 * time.Second`; missing -> `time.Duration(0)`;
  - `N int8 default:"5"` -> `int8(5)`; `N int default:"7"` -> `7`; `F float64 default:"1.5"` -> `float64(1.5)`; `B bool default:"true"` -> `true`;
  - `L []string default:"a, b"` -> `[]string{"a", "b"}`; `default:""` -> `[]string{}`;
  - `S string config:"-"` skipped; `S string config:"other"` -> segment `other`; `Token string hide:"true"` -> `Hide`;
  - `T t.Duration` with `Imports{"t": "time"}` -> duration.
- [ ] Error tests (NotValid, message contains struct and field): missing `desc`; `int8 default:"300"`; `bool default:"yes"`; `map[string]string`; embedded field; tagged unexported field; `config:"Bad_Key"`; `@Config(x=1)`; `@Config` on a function; unexported struct; package `main`.
- [ ] Graph test: `@Config Options` in package `p` and `@Provide func New(o *Options) *S` -> edge `p.Options -> p.New`; a second package with `@Config` consumed as `*p.Options` -> edge; two `@Config` in one package -> NotValid; `@Config` + a func providing `*Options` -> AlreadyExists.
