# inject `@Default` implementation switch -- Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** two or more `@Provide` of the same value plus one `@Default` make
inject generate a config-driven switch module that wires only the chosen
implementation.

**Architecture:** inject parses `@Default`, groups the providers of a value
into an `Implementation` set while building the graph, and the generator
writes one switch file per set under `gen/implementation/...`; consumers and
the root module include the switch instead of the members. builder rejects a
set where it needs one constructor and gates each member's `@Middleware`
decorator on the chosen name.

**Tech Stack:** Go 1.26, go.uber.org/fx v1.24, go-enum, text/template,
`wrapper/config`, `model/errors`.

**Spec:** `docs/superpowers/specs/2026-10-18-implementation-switch-design.md`

## Global Constraints

- Generated header: `// Code generated by inject; DO NOT EDIT.`
- Key: `<type package path relative to the module, in dots>[.<name>].implementation`;
  default value = the `@Default` member's package name; registered with
  `config.Add` in the switch file's `init()`.
- Unknown value: `fx.Error(errors.NotValidf(...))` naming key, value and the
  valid names (`"memory, unlimited"`, sorted, comma+space). No fallback.
- Validation errors fail generation; nothing is written.
- Commits in English, no `Co-Authored-By` (boost), no `Closes #N`; quality gate
  green before each push.

## Decisions made while planning (amend the spec's "Left to the builder")

- Switch file: `implementation/<type import path>/<lower ident>_implementation.go`
  under OutputDir, package `packageIdent(path.Base(type import path))` -- a
  dedicated tree, so a member importing a component of the type's package
  never makes the gen packages import each other in a cycle.
- `Ident` = type name + exported value name (`Service`, `ServiceFormal`);
  functions `<Ident>Implementation() string` (reads the key) and
  `<Ident>ImplementationModule() fx.Option` (`sync.Once`, `switch`).
- Key is env-reachable: segments split on `/` and `.`, lowercased, `_` becomes
  `.`, a hyphenated segment becomes camelCase (`sdk-go` -> `sdkGo`); the type
  in the module root uses the last element of the module path.
- Each member has exactly one `@Provide`; members must resolve to the same type
  import path; a consumer of the set declared in a member's package is
  NotValid (it would import its own switch).
- builder also rejects a set member providing server plugins.

## Review Focus

- A consumer with the set's value injected by `@Inject(name=x)` (named set):
  it gets the named switch module, not the default one.
- A consumer depending on two members' packages for other values (e.g. the
  memory package provides `Service` and a `Clock`): the `Clock` dep keeps its
  own module; only the set value goes through the switch.
- A set whose type lives outside the module (`github.com/x/y.Client`): key is
  the full import path, still env-reachable.
- Key unset: the `@Default` member is wired and its `@Middleware` runs.
- Two sets of the same type with different names: two files, two keys.

**Interfaces:**
- Produces:
  ```go
  type Implementation struct {
      Type    string               // type name ("Service")
      Path    string               // import path of the type's package
      Name    string               // fx name of the value, "" for default
      Default string               // package name of the @Default member
      Members map[string]Component // by package name
  }
  func Implementations(g *graph.Graph[Component]) ([]Implementation, error) // sorted by Path, Type, Name
  func ImplementationOf(g *graph.Graph[Component], comp Component) (Implementation, bool)
  func (i Implementation) Names() []string              // sorted member names
  func (i Implementation) Ident() string                // "Service", "ServiceFormal"
  func (i Implementation) Key(modulePath string) string // "builder.examples.simple.stock.implementation"
  func (i Implementation) File() string                 // "implementation/<Path>/<lower Ident>_implementation.go"
  func (i Implementation) Import(base string) ImportData
  func (i Implementation) Module(base string) (ImportData, string)   // call "<alias>.<Ident>ImplementationModule()"
  func (i Implementation) Chosen(base string) (ImportData, string)   // call "<alias>.<Ident>Implementation()"
  ```
  Alias: `Alias("impl", path.Base(i.Path), i.Path+"#"+i.Name)`.
