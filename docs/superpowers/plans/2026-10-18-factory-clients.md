# inject: factory clients from `@Inject` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** a `@Provide`/`@Invoke` parameter of a supported factory client type
with `@Inject` gets that client generated by inject, per `name`, with the
plugins its `@Inject` lists.

**Architecture:** clients stay out of the graph, like implementation sets:
`Clients(g)` derives them from the components' `@Inject` parameters and a
static registry (`inject/client.go`); `linkComponents` stops failing for those
parameters; the generator renders one file per client and adds its module to
each consumer's module and to the root.

**Tech Stack:** Go 1.26, uber fx, boost factories (resty v2, go-redis v9,
mongo-driver v1/v2), `text/template`.

**Spec:** `docs/superpowers/specs/2026-10-18-factory-clients-design.md`

## Global Constraints

- Default client config root = the factory root (`boost.factory.resty`);
  named client root = `<factory root>.clients.<name>`; plugin root =
  `<client root>.plugins.<plugin>`.
- Client names match `^[a-z][a-zA-Z0-9]*$` (`envSegment` in `config.go`).
- Plugin name = last segment of the plugin's config root.
- Generated file `client/<client type import path>/<name|default>_<lower type>.go`
  under OutputDir; module func `<Name|Default><Type>Module()` (resty:
  `QuoteClientModule()`, `DefaultClientModule()`), once-guarded, with
  `contextfx.Module()`.
- `init()` calls the factory's `ConfigAdd(root)` and each plugin's
  `ConfigAdd(pluginRoot)`, the default client included (duplicate keys are
  skipped by the koanf loader).
- Errors: `errors.NotValidf`, message names the component key (`gid`) and the
  parameter index.
- Commits in English, no Co-Authored-By in boost; push after every commit; no
  quality gate (disabled by the maintainer on 2026-10-18), `go build ./...` and
  `go test ./...` green before push.

## Review Focus

- `plugins=[]` (declared empty) next to a consumer with `plugins=[log]`:
  conflicting lists, error.
- `plugins=otel` without brackets: accepted as one plugin; `plugins=[otel`
  (unbalanced): error.
- A named client called `default`: its file collides with the unnamed one's;
  the generator reports AlreadyExists, never overwrites.
- Resty imported under an alias (`r "github.com/go-resty/resty/v2"`): still a
  client (resolved by import path, not by name).
- A redis `*redis.Client` and `*redis.ClusterClient` both named `cache`: two
  clients, two files (`cache_client.go`, `cache_clusterclient.go`), no clash.

  - `type ClientFactory struct { Path, Type, Build, Root string; Plugins map[string]ClientPlugin }`
    -- `Path`/`Type` of the client type (`github.com/go-resty/resty/v2`, `Client`;

  - `func clientFactory(entry annotation.Entry, tp string) (ClientFactory, bool)`:
    `*pkg.Type` only, `pkg` resolved through `entry.Imports`.
  - `func parsePlugins(raw string) ([]string, error)`: `""` -> nil; `[a, b]`
    and `a` -> names trimmed; unbalanced bracket, empty item, repeated name ->
    NotValid.
  - `func (f ClientFactory) PluginNames() []string` (sorted, for errors).

### Task 2: `Clients(g)`, the `plugins` attribute and the graph rules

**Files:**

- Modify: `inject/client.go`
- Test: `inject/client_test.go`

**Interfaces:**
- Consumes: Task 1.
- Produces:
  - `type Client struct { Factory ClientFactory; Name string; Plugins []string; Consumers []string }`
    (`Consumers` = component keys, sorted, deduplicated).
  - `func Clients(g *graph.Graph[Component]) ([]Client, error)` sorted by
    `Factory.Path`, `Factory.Type`, `Name`.
  - `func (c Client) Root() string`, `PluginRoot(name string) string`,
    `Ident() string` (`upperFirst(name or "default") + Type`: `QuoteClient`),
    `File() string` (`client/<Path>/<name|default>_<lower Type>.go`),
    `Import(base string) ImportData` (alias `Alias("client", path.Base(Path), p)`),
    `Module(base string) (ImportData, string)` (`<alias>.<Ident>Module()`).

Rules (`Clients` returns NotValid; `NewGraphFromEntries` returns its error):
a client parameter = `@Inject`, no `group`, type resolved by `clientFactory`,
and no component provides its id (`injectID`). `plugins` on any other
parameter, on a client the app provides, or with `group` -> error; invalid
name; unknown plugin (message lists `PluginNames()`); different lists for one
client (message names both consumers); `plugins` on `@Provide` -> error.
