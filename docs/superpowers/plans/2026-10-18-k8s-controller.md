# builder `@Controller` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `@Controller(on=…)` on a `func(context.Context, *T) error` makes `go generate` build an app that connects to the cluster and calls the function on that event of `T`; `@CRD` on a struct makes it write the CRD YAML, the DeepCopy and the scheme registration.

**Architecture:** A new factory builds a controller-runtime manager from the existing `boost.factory.k8s.*` config. A runtime package (`bootstrap/controller`) turns the four events into one typed controller per watched type (typed request = object key + event, finalizer for `deleted`). The builder parses `@Controller`/`@CRD` into the spec, renders `controller_module.go` (one `controller.Register` per type), `deploy/rbac/<app>.yaml`, and, through controller-tools fed with in-memory markers, `deploy/crd/*.yaml` and `zz_generated.boost.go`.

**Tech Stack:** Go 1.26, `sigs.k8s.io/controller-runtime v0.25.2`, `sigs.k8s.io/controller-tools v0.23.0`, `k8s.io/api|apimachinery|client-go v0.37.x`, `k8s.io/apiextensions-apiserver v0.37.x`, go.uber.org/fx, golang.org/x/tools (packages, imports).

**Spec:** `docs/superpowers/specs/2026-10-18-k8s-controller-design.md`

## Global Constraints

- Generated Go files start with `// Code generated by builder; DO NOT EDIT.`; generated YAML with `# Code generated by builder; DO NOT EDIT.`.
- Factory config root `boost.factory.controllerruntime`: `namespace` `""`, `resync` `10h`, `leaderElection.enabled` `true`, `leaderElection.id` `""` (empty = app name), `health.addr` `:8081`, `metrics.addr` `:8082` (spec said `:8080`, which is echo's default port; the spec is corrected in the same commit as this plan).
- Builder config: `boost.builder.deploy`, default `deploy`, must be inside the Go module.
- `on` values: `created`, `updated`, `deleted`, `sync`. Annotation keys: `on`, `owns`, `selector`, `app` (`@Controller`); `group`, `version`, `scope`, `plural` (`@CRD`). `scope` ∈ `Namespaced` (default), `Cluster`; `plural` default `strings.ToLower(kind)+"s"`.
- A selector with a comma must be quoted: `selector="app=web,tier!=db"` (the annotation splits values on top-level commas).
- Finalizer name: `boost.xgodev.io/<app>`. Controller name: `strings.ToLower(kind)+"."+group`, with group `core` for the empty group.
- Door file `gen/builder/<app>/controller_module.go`; the server name `controller` is reserved like `function`.
- controller-runtime is only instantiated inside `factory/contrib/sigs.k8s.io/controller-runtime/v0` (Iron Law 4); logs reach `wrapper/log` through a logr sink.
- Commits in English, no `Closes #N`, push after each commit, comment on #109 per push (hash, files, build, test).

## Review Focus

1. A stale `zz_generated.boost.go` after the dev changes the `@CRD` struct (field renamed) → `go generate` still succeeds and rewrites it (the loader overlays the fresh file, never type-checks the stale one).
2. The controller run outside the cluster (kubeconfig) with leader election on and `namespace` empty → it starts, the lease goes to namespace `default` (in cluster: the pod's namespace).
3. An object with the finalizer whose labels leave the `deleted` selector, then deleted → `deleted` still runs and the finalizer is removed (a held finalizer is never orphaned by the selector).
4. A status-only update (the handler writing status) → no `updated`, no `sync` (no self-triggered loop); a periodic resync (same resourceVersion) → `sync` only.
5. A `@CRD` removed from the code → its `deploy/crd/*.yaml` is removed on the next generate (stale YAML with the header is cleaned like stale Go).

### Task 2: Runtime — `bootstrap/controller`

**Files:**
- Create: `bootstrap/controller/{controller.go,register.go,events.go,reconciler.go,own.go,README.md}` + `_test.go`
- Create: `fx/modules/bootstrap/controller/module.go`

**Interfaces:**
- Consumes: Task 1 `Module(app, schemes...)`, `manager.Manager`.
- Produces:
  - `type Func[T any] struct { Call func(context.Context, *T) error; Selector string }`
  - `type Handlers[T any] struct { Created, Updated, Deleted, Sync *Func[T]; Owns []client.Object }`
  - `func New(app string, mgr manager.Manager) *Controller`
  - `func Register[T any, PT interface{ *T; client.Object }](c *Controller, h Handlers[T]) error` — one typed controller per call; error for an invalid selector or a second registration of `T`.
  - `func Own(owner, obj client.Object) error` — controller owner reference with the scheme of the running app (NotValid before `New` or for a type outside the scheme).
  - fx: `Module(app string, schemes ...func(*runtime.Scheme) error) fx.Option` — includes Task 1's module, provides `*Controller` and `client.Client` (`mgr.GetClient()`), runs `mgr.Start` in an OnStart goroutine, cancels on OnStop, `Shutdowner.Shutdown(fx.ExitCode(1))` when Start fails (pattern of `fx/modules/bootstrap/function/module.go`).

Event routing (typed request `{key types.NamespacedName; event}` on `source.TypedKind` + `handler.TypedFuncs`):

| informer event | enqueued |
|---|---|
| Create, `IsInInitialList` | `sync` (if Sync or Deleted); `deleted` if deleting and holds the finalizer |
| Create, live | `created` (if Created), `sync` (if Sync or Deleted) |
| Update, new has DeletionTimestamp | `deleted` (if Deleted and holds the finalizer) |
| Update, same resourceVersion (resync) | `sync` |
| Update, `changed(old,new)` | `updated` (if Updated), `sync` (if Sync or Deleted) |
| Delete / Generic | nothing |
| owned object event | `sync` of the controller owner whose GVK is `T` |

`changed(old,new) = generation differs || labels differ || annotations differ || (new.Generation == 0 && resourceVersion differs)`.

Reconcile: get (NotFound → done); deleting → if it holds the finalizer, call Deleted, on nil remove the finalizer; never call Sync. Not deleting → if Deleted exists, its selector matches and the finalizer is missing, add it; then call the request's function if its selector matches. A function error is returned (controller-runtime retries with backoff).
